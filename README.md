## 🚀 Featured Project — Readapt

**Readapt** is an accessibility-focused reading ecosystem designed to make written content easier to consume for people with dyslexia.

It combines an AI-powered Rails application with a lightweight Chrome extension, approaching accessibility at two complementary levels: deeper content transformation and direct browser-level reading adaptation.

### 🧠 [Readapt Web](https://github.com/TonyLawrence85/readapt)

AI-powered reading assistant built with **Ruby on Rails 8**.

**Highlights:**

- AI-assisted text adaptation with meaning-preservation constraints
- text, PDF and image input
- multimodal AI processing
- accessible typography and configurable reading preferences
- text-to-speech generation
- Whisper-based transcription and timestamp processing
- synchronized text/audio reading
- authentication and user-scoped authorization
- background processing with Active Job
- automated tests and GitHub Actions CI
- RuboCop, Brakeman, Bundler Audit and Dependabot

**Stack:** Ruby · Rails 8 · PostgreSQL · Hotwire · Stimulus · OpenAI · RubyLLM · Whisper · Google Cloud TTS · Active Storage · Solid Queue · Docker · Kamal

[Explore Readapt Web →](https://github.com/TonyLawrence85/readapt)

### 🌐 [Readapt Chrome Extension](https://github.com/TonyLawrence85/readapt-chrome-extension)

A **Manifest V3 browser accessibility extension** that adapts websites directly in Chrome.

**Highlights:**

- OpenDyslexic and alternative reading fonts
- configurable text size and spacing
- adjustable line height
- mouse-following reading ruler
- per-site activation controls
- synchronized preferences with `chrome.storage.sync`
- local page adaptation without a remote AI dependency
- zero-dependency automated Node.js tests
- GitHub Actions CI

**Stack:** JavaScript · HTML · CSS · Chrome Extensions API · Manifest V3 · Node.js testing

[Explore the Chrome Extension →](https://github.com/TonyLawrence85/readapt-chrome-extension)
